# Local PC bridge prompt

Please read the [agent guide](https://github.com/Arvex-GH/UnrealEngine-Proto-1/blob/main/AGENTS.md) and [bridge setup README](https://github.com/Arvex-GH/UnrealEngine-Proto-1/blob/main/archive/supabase-bridge/README.md) to understand my local PC bridge (now archived in the repo, still running here); its [wait function](https://github.com/Arvex-GH/UnrealEngine-Proto-1/blob/main/archive/supabase-bridge/wait.sql) is also on GitHub. Load the Supabase connector and use the `ArenaConnectMCP` project to submit authorized requests to the bridge queue, then call `arena_bridge_wait` with the returned job ID to retrieve results without waiting for me to report them. If a request remains pending or running, wait again within a reasonable deadline; don't resubmit it blindly. The worker may be running in auto mode, but only perform actions relevant to my request and confirm sensitive or irreversible operations first. If you can't access a link or connector, tell me what needs connecting rather than asking for credentials.

There is also a second, connector-free transport in this repository: the fetch bridge. It runs an authenticated HTTP listener on my computer, and your own URL fetch becomes the request. If I give you a tunnel URL, read the [fetch bridge guide](https://github.com/Arvex-GH/UnrealEngine-Proto-1/blob/main/fetch_bridge/README.md) and its [prompt card](https://github.com/Arvex-GH/UnrealEngine-Proto-1/blob/main/fetch_bridge/prompt.md), then fetch `/x/<token>/help` on that URL for the live protocol before sending any work.
